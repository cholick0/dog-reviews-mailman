A make.fun entry: one funny one-line review a dog gives the mailman, under 200 characters.

`main.ts` (Node 22) writes the review to `/output/entry.txt`, validates it against the gate (1–200 characters, one line, not only whitespace), then reads it back byte-for-byte to confirm it matches.
